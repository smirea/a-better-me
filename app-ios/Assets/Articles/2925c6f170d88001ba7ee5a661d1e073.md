Instead of using a moderately staggered stance, you have the option of performing the single arm overhand grip landmine row with a symmetrical approximately shoulder width stance if you prefer. As an alternative to grasping the barbell’s sleeve directly, you can also perform this exercise while grasping a landmine attachment that has a single handle. If you have access to this attachment and wish to use it, slide it onto the barbell’s sleeve before adding the weight plates, then row using the same technique described above.

As an alternative to setting the bar at its lowest height in the Smith machine, you can start with the bar elevated to the height of your knees/lower thighs. Doing so would reduce the depth at which you have to hinge to grasp the bar before picking it up, which can make it somewhat easier to assume the starting position for this exercise. If you opt to start with the bar racked in an elevated position, you would have to rotate the safety hooks out away from the safety bars through a slight wrist flick motion while you start standing up with the bar, so that the safety bars do not catch the safety hooks.

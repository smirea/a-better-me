To save time when setting up during future sessions, it can be useful to record which number handle position you determined to place you in the proper starting position for this exercise if you will repeatedly use the same machine. Besides reducing the time required to re-adjust the handles, ensuring you use the same handle position from session to session helps track progress over time. Since changing the handle position can affect the range of motion you use for this exercise, it can correspondingly influence the difficulty of each rep. In turn, this can affect how many reps you can perform with a given weight or how much weight you can use for a given number of reps.

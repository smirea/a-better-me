With a rather heavy load, getting into the starting position and returning the weight to the ground can be awkward and difficult when setting up a landmine goblet squat with the plates on the ground. To circumvent this challenge, you have the option of performing the bottoms-up landmine goblet squat, where you set up with the weight on an elevated object like a plyometric box, aerobic step with risers, or a flat exercise bench. Doing so lets you start from the bottom with the weight in the goblet position and set it by squatting until the plates rest on the object, rather than switching grips before lowering the bar. The elevated object can also function as safety pins in a power rack, absorbing the load if you fail a rep. When utilizing the same squat depth, load, and volume, the two methods of performing the landmine goblet squat can provide the same stimulus to your muscles. However, they are presented as two distinct exercise pages in this database because the set-up instructions differ for each approach, and the sets begin from different positions. While quite useful for heavy loads, the cons of the bottoms-up method are that it requires additional equipment and takes more time to set up.
